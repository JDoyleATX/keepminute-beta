# KeepMinute beta

Thank you for trying KeepMinute before it launches.

KeepMinute records your calls in any app on your Windows PC, such as Teams, Zoom, Google Meet or a phone app, and turns them into notes and summaries. Your recordings and notes stay on your PC. You connect your own AI account, and your recordings go only to the services you connect.

This is a beta for friends. It is free to use until 30 November 2026, and it opens without a licence key. It runs on Windows 10 and Windows 11.

## Install

1. Download **KeepMinute-Setup-1.2.0-beta.exe** from the [latest release](https://github.com/JDoyleATX/keepminute-beta/releases/latest).
2. Double-click the file to start the installer.
3. Windows may show a blue box saying "Windows protected your PC". This is expected for a new installer. Click **More info**, then **Run anyway**.
4. Follow the installer. When it finishes, search the Start menu for **KeepMinute** to open it.

## First-run setup

The first time you open KeepMinute, it walks you through setup.

You will need an API key from your own AI provider account. The setup screen links to each provider and shows the steps once you have an account. Your provider bills you directly for what you use.

Connecting Outlook or Google Calendar is optional. You can skip it and add it later in Settings.

## Report a bug

Bug reports are the most useful thing you can send. In the app, go to **Help > Report a bug**, or use the Report a bug button on the main window. It adds basic system details to help us find the problem. You can also email support@keepminute.com.
